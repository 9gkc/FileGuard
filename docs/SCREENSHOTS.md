# FileGuard UI Screenshot Verification

The repository screenshots are captured from the running FileGuard interface, not visual mockups. They show the initial local-triage workspace in its two supported interface languages.

| Screenshot | Verified state |
| :--- | :--- |
| `docs/images/fileguard-en.webp` | English left-to-right workspace with the local-only, no-execution, no-upload commitment and the unanalysed-file state. |
| `docs/images/fileguard-ar.webp` | Arabic right-to-left workspace with the same product capabilities, privacy wording, and local-triage controls. |

The screenshots deliberately show the empty queue rather than a synthetic incident result. They therefore make no unsupported malware-detection claim and accurately represent FileGuard before a user selects a local file.
